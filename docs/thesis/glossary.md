# Glossary

- MDP: Markov Decision Process (Thesis).
- MCTS: Monte Carlo Tree Search (Thesis).
- EMD/Wasserstein: Earth Mover’s Distance used over abstract transitions (Thesis).
- Abstraction: clustering of ground states into abstract states (Thesis).
- Homomorphism: structure-preserving mapping between MDPs (Thesis).
- Composite z: standardized structural minus standardized performance score (Thesis).
