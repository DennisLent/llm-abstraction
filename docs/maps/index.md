# Maps & Abstractability

- Map sizes: 3×3, 5×5, 9×9 configured in `config.yml` under `game`.
- Abstractability factor: `R = (n − k) / n`, where `n` is ground states and `k` abstract states.
- Categories: none/partial/perfect; current classifier labels using thresholds in `llm_abstraction/utils/classify.py` (≥ 0.25 → "perfect", > 0 → "partial").
- Symmetry matters: more symmetric layouts yield higher abstraction quality and planning gains (Thesis).
- Thumbnails: generated by `preview-maps` under `outputs/maps/<map_hash>/`.
