SRQ1: We performed an ANCOVA on abstraction difficulty (abstractability) and found a significant main effect (F=1997.93, p=0), indicating that maps that are fully abstractable yield higher abstraction scores. This shows LLMs can approximate the optimal abstraction when it exists.
SRQ2: Using a mixed-effects model accounting for map-level variance, we estimated average abstraction scores. The best-performing model achieved an average score of 0.226, demonstrating that LLM-based abstractions reach sufficient quality to be actionable in planning tasks.
SRQ3: An ANCOVA testing model, prompt variation, and map size revealed significant main effects on abstraction quality: model (F=28.54, p=1.93e-39), prompt (F=12.86, p=1.02e-24), and size (F=54927.13, p=0). Interaction plots illustrate how these factors jointly influence performance.
SRQ4: Post-hoc Tukey HSD comparisons for each map identified the top-performing LLMs. Across all maps, the leading models are deepseek-r1:7b, deepseek-r1:32b, deepseek-r1:70b, with deepseek-r1:7b consistently outperforming others.
SRQ5: The significant main effect of prompt ID indicates that abstraction scores vary by prompt phrasing, highlighting the importance of carefully designing prompt templates.
SRQ6: ANOVA on representation method shows a significant effect (F=45.86, p=1.3e-11), indicating some encoding schemes yield clearer abstractions for LLMs.
SRQ6: The choice of output format also influences scores (F=18.58, p=8.67e-09), suggesting that structured or compact formats may aid LLM comprehension.
SRQ7: A significant interaction between model and abstractability (F={anc2_table.loc['C(model):C(abstractability)', 'F']:.2f}, p=2.97e-22) indicates that while all models degrade when perfect abstraction is impossible, some handle complexity better.
